# External archive index

Search `external_archive_manifest.csv` before assuming that missing historical material was deleted without preservation. Each row identifies the original location, verified external ZIP, checksum manifest, pointer, and restoration command.

The indexed archives are dormant and are not required by current production. Active MLB/NHL models, current data, databases, prospective ledgers, environments, Retrosheet, the 2026 Hits rebuild, source configuration, and secrets remain local.

An archive is restorable only after its external `metadata.txt`, `archive.sha256`, `verification.txt`, and per-file `source_files.tsv` have been checked.
