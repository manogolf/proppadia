# Slate snapshot policy

`HITS05_SLATE_SNAPSHOT_POLICY = 09:00_AMERICA_NEW_YORK_DATE_LEVEL_ACTIVE_ROSTER_STRICT_PRIOR_DATE_FEATURES`

Every game on a date—including both doubleheader games—uses the same morning state. Only games completed on earlier dates enter histories or training. The StatsAPI roster endpoint is dated but not intraday-versioned; this is disclosed as a limitation.
